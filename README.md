# TypeBig

Type anything and it fills the whole screen. The more you type, the smaller the text gets, so it always fits.

Good for showing a message across a room, holding up a sign on a phone or tablet, or putting a big word on a projector.

**Try it:** https://yitz42.github.io/TypeBig/

## How to use

- Just start typing. The text grows to fill the screen and shrinks as you add more.
- **Fullscreen** button (or `Ctrl/⌘ + Enter`) hides the browser around it.
- **Dark / Light / Bold** changes the colors.
- **Sans / Serif / Mono** changes the font.
- **Clear** (or press `Esc` twice) wipes the text.
- Press `Enter` for a new line.
- The controls hide while you type. Move the mouse to bring them back.
- Your text, colors and font are remembered in your browser.

### Link straight to a message

Add `?text=` to the URL to open with text already on screen:

```
https://yitz42.github.io/TypeBig/?text=Hello%20world&theme=contrast&font=serif
```

`theme` can be `dark`, `light` or `contrast`. `font` can be `sans`, `serif` or `mono`.

## Run it locally

It's a single file with no dependencies. Open `index.html` in any browser.
